Goldeneye Version Beta : Cheats

On ne sait pas grand chose des Cheat Options Beta. Voilà toutefois quelques trucs bien sympas, comme le Fameux Line Mode ! Pour commencer, les Codes "NO NAME" qui sont accessibles avec l'Action Replay. Les Codes NO NAME activent des trucs différents, mais portent tous le même nom. Voici les Codes et ce qu'ils activent !

Le Code de Base est 800696XX 0001 : remplacez les XX par...

  • 51 - Extra Characters
  • 54 - Maximum Ammo (Munitions au Maximum mais PAS Infinies)
  • 57 - Line Mode (Mode Fil de Fer)
  • 58 - Super 2X Health
  • 59 - Super 2X Armor
  • 5D - Extra Weapons
  • 60 - Super 10X Health
  • 66 - Invisible (Multi)
  • 69 - Debug Mode
