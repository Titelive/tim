Perfect Dark : Avoir TOUTES les Armes en Double en Mode Solo

Un Code Magnifique, qui vous permet de porter TOUTES les Armes du jeu en Double, en Mode Solo. En fait, le Jeu duplique le Modèle de Droite (Joanna est droitière) pour le greffer à la Gauche de l'Ecran, en changeant la vue. C'est assez drôle, car désormais, vous avez 4 mains ! Pour le Laser, ça ne change rien, il apparaît juste à la Gauche de l'écran, on ne peut pas en avoir deux. Pour les Remote Mine, ça ne change rien. Enfin, pour le Slayer, ça ne fonctionne que dans les Niveaux où on peut l'utiliser (Skedar Ruins et WAR!). Evidemment, ce Code n'est amusant que si vous le combinez avec les Codes All Guns et Infinite Ammo... Sinon vous ne pourrez pas vous servir des Armes puisque pas de cartouches !

Les Armes concernées : Callisto NTG, RCP-120, Laptop Gun, Dragon, K7 Avenger, AR-34, Super-Dragon, Timed Mine, Reaper, Sniper Rifle, Remote Mine, Devastator, Rocket Launcher, Crossbow, Tranquilizer, Grenade.
